# Code of conduct

## Our standard

UnDiffused should be a useful place to learn, test ideas and improve technical
work. Contributors are expected to be direct, respectful and evidence-led.

Positive behaviour includes:

- criticising ideas and implementations without attacking people;
- explaining technical disagreements with reproducible evidence;
- welcoming questions from people with different experience levels;
- giving credit for research, code, reports and vulnerability findings;
- handling private images, security reports and personal information carefully;
- correcting inaccurate claims openly.

Unacceptable behaviour includes harassment, discrimination, threats, sexualised
conduct, deliberate humiliation, publishing private information, or sustained
bad-faith disruption.

## Scope

This standard applies in repository issues, pull requests, discussions, security
reports and other project spaces. It also applies when someone represents the
project publicly.

## Reporting

For ordinary conduct concerns, contact the repository owner through their GitHub
profile. For a concern tied to a security report, use the private advisory thread
described in [`SECURITY.md`](SECURITY.md).

Reports will be reviewed in context. Responses may include a warning, removal of
content, temporary restriction or permanent exclusion from project spaces.

## Attribution

This is a project-specific conduct policy written for UnDiffused. It is not a
substitute for GitHub's platform policies.
